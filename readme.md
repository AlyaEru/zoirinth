# Zoirinth

Kill zoids! Get clovers!

# Installation

**Prerequisites:** Assumes you have git and docker-compose installed. Also assumes you have a reverse proxy pointing the domain in highscores.js to port 3000, and /api to 3001. If these steps do not work for you, please submit an issue describing what went wrong.

```
git clone ...
cd zoirinth
docker-compose up -d
```
